# Code of Conduct

This project follows the spirit of the Contributor Covenant. In short: be respectful, stay on topic, and don't make the issue tracker a worse place than the code.

## Our standards

- Critique code and design, not people.
- Assume good faith until shown otherwise.
- Keep discussions technical.

## Unacceptable

- Harassment, personal attacks, or hate speech
- Publishing others' private information
- Spam or crypto solicitations
- Deliberate misinformation about how pi or this extension works

## Enforcement

The project owner may remove, edit, or reject comments, issues, and pull requests that violate this code. Repeated or severe violations result in a ban.

To report a violation, use GitHub private security advisories or contact the owner through GitHub.
